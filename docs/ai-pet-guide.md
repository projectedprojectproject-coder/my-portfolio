# AI 펫 투어 가이드 (펫 모습 교체 · 내 목소리 음성 · 대화형)

사이트 오른쪽 아래 "소개 듣기" 버튼 → 펫이 섹션을 스크롤하며 자막(+음성)으로 소개합니다.
코드 위치: `src/tour/` (대본 `tourScript.js`, 펫 모습 `petConfig.js`·`PetAvatar.jsx`, 동작 `TourPet.jsx`).

## 1. 펫 모습 바꾸기 (나중에)
1. 그림 파일을 준비합니다. 배경이 투명한 **정사각형 PNG / SVG / WebP / GIF** 한 장이면 됩니다(권장 512×512).
2. 파일을 `public/pet/` 폴더에 넣습니다. 예: `public/pet/pet.png`
3. `src/tour/petConfig.js` 에서 `image: "/pet/pet.png"` 로 바꿉니다. (`null` 이면 임시 펫)
4. 말하는 동안 그림이 살짝 통통 튑니다. 입 모양까지 움직이는 캐릭터가 필요하면 말한다는 신호(`speaking`)를 쓰는 `PetAvatar.jsx` 만 고치면 됩니다.

## 2. 내 목소리 음성 만들기 (가이드라인)
핵심 원칙: **API 키는 사이트 코드·저장소·대화창에 절대 넣지 않습니다.** 음성은 미리 mp3 파일로 만들어 사이트에 올리므로, 방문자가 들을 때는 키도 서버도 비용도 필요 없습니다.

### 순서
1. **서비스 선택**: 내 목소리 복제를 지원하는 음성 합성(TTS) 서비스에 가입합니다. 예시는 ElevenLabs(한국어 지원). 요금·한국어 품질·약관(상업적 이용, 음성 소유권)을 가입 전에 확인하세요.
2. **녹음**: 조용한 곳, 가까운 마이크, 배경 음악·울림 없이 1~3분. 평소 말투로 천천히 또렷하게 읽습니다. 잡음이 적을수록 복제 품질이 좋아집니다.
3. **복제 음성 만들기**: 서비스의 "Voice Clone"(Instant Clone 등)에 녹음 파일을 올립니다. 본인 목소리인지 확인하는 동의 절차가 있을 수 있습니다.
4. **Voice ID와 API 키 확인**: 만든 음성의 ID, 계정 설정의 API 키. 키는 비밀번호처럼 다룹니다(공유·캡처 금지, 노출되면 즉시 폐기 후 재발급).
5. **음성 파일 생성** (내 PC 터미널, PowerShell):
   ```powershell
   $env:ELEVENLABS_API_KEY = "여기에_내_API_키"
   $env:ELEVENLABS_VOICE_ID = "내_복제_음성_ID"
   npm run tour:voice
   ```
   `public/audio/tour/01-hero.mp3` … `10-contact.mp3` 가 생깁니다. 다시 만들 때는 `npm run tour:voice -- --force`.
   (키 없이 하고 싶다면: 서비스 웹 화면에서 대본을 한 단계씩 붙여 넣어 mp3를 받아 같은 이름으로 넣어도 됩니다.)
6. **들어 보고 고치기**: 어색한 문장은 `tourScript.js` 의 `text` 를 고친 뒤 `--force` 로 다시 만듭니다. 영어·숫자는 한글 발음으로 풀어 쓰면(예: 디앤디) 읽기가 자연스럽습니다.
7. **배포**: 푸시하면 파일이 함께 올라갑니다. 파일이 없는 단계는 자막만 나오고 자동으로 넘어갑니다.

### 주의
- API 주소·모델 이름은 서비스 문서 기준으로 달라질 수 있습니다. 실패하면 오류 메시지를 확인하세요. (`scripts/generate-tour-voice.mjs` 맨 위 설명 참고)
- `.env` 에 키를 적어 두더라도 저장소에는 올라가지 않게(`.gitignore`) 유지하세요.
- 음성 파일은 한 개 100~400KB 정도라 용량 부담이 작습니다.
- 내 목소리가 외부 서비스에 학습·저장됩니다. 약관의 음성 데이터 보관·삭제 정책을 확인하세요.

## 3. 대화형 (선택, 나중에)
방문자가 직접 질문(예: "연구 주제가 뭐예요?")을 입력/말하면 AI가 즉석에서 답하는 방식입니다. 지금의 투어는 **정해진 대본만** 말합니다.

### 필요한 것
- **서버 쪽 함수**(Vercel Serverless Function): 브라우저에서 질문을 받아 AI API를 대신 호출합니다. AI 키는 이 함수의 환경 변수에만 둡니다. 사이트 코드에 넣으면 누구나 훔쳐 쓸 수 있습니다.
- **사이트 정보만 답하게 하는 지침**(시스템 프롬프트): 포트폴리오 내용(소개·연구·프로젝트 등)만 근거로 답하고, 모르면 모른다고 하게 합니다.
- **사용량 제한**: 방문자당 횟수·길이 제한, 일일 한도. 없으면 악용 시 요금이 크게 나올 수 있습니다.
- **음성으로 답하려면**: 답변을 그때그때 TTS 서비스로 변환해야 하므로 지연과 비용이 추가됩니다. 글(자막)로만 답하게 하는 것이 가장 단순합니다.

### 단계
1. 글로만 답하는 채팅 창(펫 말풍선 안) → 2. 서버 함수 + 키 보관 + 사용량 제한 → 3. (선택) 답변 음성화

### 비용·위험
- 호출량만큼 요금이 듭니다(소량이면 작지만 한도 설정 필수).
- AI가 사이트에 없는 내용을 지어낼 수 있어, 근거 범위를 좁히는 지침과 점검이 필요합니다.
- 방문자 질문이 외부 AI 서비스로 전송되므로 개인정보 안내가 필요할 수 있습니다.
